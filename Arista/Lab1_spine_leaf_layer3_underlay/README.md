### Introduction

Lab 1 is the first lab of ***Network Automation with Ansible*** lab series on Arista Network.

Lab 1 covers the following configurations of Layer 3 Spine Leaf network:
 - `banner login` and `banner motd`

### Requirements
- **Control node:** one control node where ansible is installed

- **Managed nodes:** six managed nodes, also known as target nodes, where the configuration changes or modifications are applied:
  - Two spine nodes
  - Four leaf nodes
